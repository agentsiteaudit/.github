AgentSiteAudit

Website audits built for AI agents. Send one URL, get one structured JSON report: a score, issues in priority order, and evidence plus an exact fix for every check.

69 checks across ten categories; permanent check IDs; every result is PASS, WARNING, FAIL or NOT_TESTED (NOT_TESTED is never a pass).
API: GET https://agentsiteaudit.com/v1/audit?url=... , 0.01 USDC per audit on Base (x402 v2, exact scheme), no account, no key.
MCP server for Claude, Cursor and other tools: https://agentsiteaudit.com/mcp/ (audit_site, verify_fixes, customer_reaction, list_checks; 5 free audits a day).
Machine-readable: llms.txt, skill.md, OpenAPI 3.1 and the full check registry.
